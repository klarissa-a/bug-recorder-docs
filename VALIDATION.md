# Проверка сайта

- npm install: успешно; после обновления Vite — 0 известных уязвимостей по npm.
- npm run docs:build: успешно, включая проверку внутренних ссылок VitePress.
- npm run docs:dev: сервер запускается, главная отвечает HTTP 200.
- npm run docs:preview: сервер запускается, production-сайт работает.
- Headless Chromium через Playwright: все 30 страниц отвечают HTTP 200 и содержат заголовок; переход на статью и перезагрузка работают.
- Локальный поиск находит результаты по всем 11 словам из ТЗ: Network, шаги, запись, ОР, ФР, заголовок, вкладки, пароль, панель, установка, Telegram.
- Проверены переключение светлой/тёмной темы и переход через боковое меню на ширине 390 px.
- На проверенных мобильных главной и статье нет горизонтального переполнения страницы.
- Во время браузерной проверки ошибок JavaScript не обнаружено.
- Синтаксис theme/index.js проверен через node --check.
- Обязательная сборка расширения npm run build и разбор src/manifest.json и dist/manifest.json прошли; исходники расширения не изменялись.

Снимки самого сайта сохранены в previews/. Это не скриншоты интерфейса расширения для статей. Реальные скриншоты Recorder и уточнения перечислены в CONTENT_REVIEW.md.

Сайт не публиковался в GitHub или Vercel. Работа внешних каналов обратной связи и установка расширения из магазина не тестировались.
