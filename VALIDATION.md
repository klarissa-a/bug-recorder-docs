# Проверка сайта – 3 октября 2026

## Результат

- `npm.cmd run docs:build` в исходном проекте bug-recorder-docs – успешно. Проверены ссылки VitePress и чтение всех PNG обработчиком скриншотов.
- `git diff --check` – без ошибок. Предупреждения Git о будущем преобразовании LF в CRLF не являются ошибками содержимого.
- Все **33 страницы production-сборки** проверены в Chromium на ширинах **1440, 390 и 320 px**: HTTP 200, заголовок присутствует, горизонтального переполнения страницы нет.
- Проверено **58 локальных адресов** ссылок и изображений: HTTP 200. Все **155 переходов по якорным ссылкам** ведут к существующим элементам страниц.
- Выполнено **111 проверок изображений** в статьях на трёх ширинах. Все **25 уникальных PNG** загружаются, имеют alt, сохраняют пропорции, не выходят за экран; маски и clip-path отсутствуют, родитель не обрезает высоту.
- Для каждого изображения проверена плотность не ниже 2 исходных пикселей на CSS-пиксель при отображении в статье.
- Клик по скриншоту открывает исходный PNG в новой вкладке – проверено на странице редактирования шагов.
- Локальный поиск возвращает результаты по Console, Network, предусловие, 500 и тест-кейс. В production-сборке дополнительно проверен поиск «сворачивание».
- Проверены светлая/тёмная тема и переходы на тест-кейс и RU / EN через мобильное меню «Разделы».
- Повторно проверены все 32 перехода бокового меню с ожиданием правильного заголовка целевой страницы.
- В открытой вкладке пользователя после обновления успешно проверены «Первая запись», RU / EN и изображение на странице установки.
- На ширинах 1440, 1100, 390 и 320 px подписи «Разделы» и «На этой странице» имеют размер 16 px; подсказка горячих клавиш в кнопке поиска скрыта.
- На окончательном проходе страниц ошибок JavaScript не получено.
- Независимая read-only сверка документации с исходниками существенных новых неточностей не выявила.
- GitHub Actions переведён с Node.js 20 на **24**, что соответствует `node >=22` в package.json и package-lock.json. Локальная сборка выполнена на Node.js **24.16.0**; удалённый запуск GitHub Actions не выполнялся.

## Визуальная проверка

Главная дополнена полноценным скриншотом выбора режима: справа от текста на широком экране и после кнопок на узком. Проверены 14 сочетаний светлой/тёмной темы и ширин 1920, 1440, 1100, 960, 768, 390 и 320 px. Везде отображается нужный PNG, сохраняются пропорции и плотность 2x, нет обрезки или горизонтального переполнения. Переход «Начать работу» проверен. Дизайнер отдельно просмотрел desktop, mobile и dark preview; существенных визуальных дефектов не выявлено. Текст блока возможностей переписан через практическую пользу без количественных обещаний экономии времени.

PNG сняты с настоящей сборки QA Lis 0.25.2 в отдельном профиле Chromium, deviceScaleFactor 2. Девять прежних снимков заменены, шестнадцать добавлены. Для кадра проверялись границы целевого интерфейса и внешний отступ 16 CSS px. Длинные отчёты сняты целиком в высоком окне, без изменения стилей расширения.

В итоговой правке добавлен настоящий снимок мини-панели на паузе с треугольником продолжения слева от луны. Проверены Pause → Resume → Stop, сворачивание и разворачивание готового отчёта; записанные шаги сохранились. Отдельный снимок редактирования шагов показывает фокус именно на поле шагов. Свёрнутый отчёт переснят без края всплывающей подсказки. Расположение кнопок сворачивания и разворачивания объяснено рядом с крупными значками. Независимый read-only просмотр этих правок дефектов не выявил.

Просмотрены полный баг-репорт, тест-кейс, редактор/добавление шага, детали запроса, полная панель в обеих темах, английская панель и состояние связанной вкладки. На мобильной странице проверены читаемость, пропорции и доступ к исходному размеру.

Актуальные снимки сайта находятся в `previews/`: главная на широком и узком экране, тёмная тема, статья на двух ширинах и проверка краёв скриншотов.
