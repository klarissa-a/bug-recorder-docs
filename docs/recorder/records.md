# Наборы багов и тест-кейсов

## Отдельный набор для каждого режима

QA Lis хранит до **трёх багов** и отдельно до **трёх тест-кейсов**. Режим выбирается вне активной записи. Переключение режима сохраняет оба набора.

## Добавить следующую запись

Нажмите **+** рядом с записями либо **Новый баг / Новый тест-кейс** в отчёте. Текущая запись сохраняется и завершается, начинается следующая. Её Network-счётчик начинается с **0 / 120**.

![Набор из двух багов в полной панели: текущая запись отмечена красной точкой](/images/recorder/records-light.png)

В каждой записи свои шаги, поля отчёта, Network и Console. Запрос относится к записи, в которой он начался, даже если ответ пришёл позднее.

## Посмотреть предыдущую запись

В полной панели нажмите её номер, в мини-панели раскройте список **Баг N/3** или **Тест-кейс N/3**. Просмотр предыдущей записи ставит текущую на паузу. Кнопка продолжения возвращает к текущей записи.

В готовом отчёте можно переключаться между записями кнопками сверху. Правки сохраняются перед переключением.

## Когда достигнут лимит

После третьей записи вместо добавления появляется **Нужно больше?** с пояснением и ссылкой на Telegram. Для нового набора сначала скопируйте нужные отчёты и нажмите **Начать новую запись**. Это заменит весь набор выбранного режима.
