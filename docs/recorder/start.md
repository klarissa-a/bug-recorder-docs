# Начало записи

## Начать запись
Откройте Recorder по иконке расширения. В состоянии **Готов к записи** нажмите **Начать запись**.

![Recorder до начала записи: статус «Готов к записи», выбор языка и кнопка «Начать запись»](/images/recorder/ready-dark.png)

После успешного старта панель сворачивается в мини-вид. Появятся статус **Идёт запись**, таймер и счётчики. Действия на сайте начнут преобразовываться в шаги; доступные сетевые запросы будут собираться вместе с записью. При необходимости разверните панель обратно.

Воспроизводите один сценарий ошибки. Проверяйте [список шагов](../steps/view.md), чтобы вовремя заметить лишние действия.

## Если уже есть черновик
Вместо обычного старта отображается **Начать новую запись**. Это действие очищает предыдущую запись. Чтобы сохранить её текст, сначала нажмите **Открыть баг-репорт** и скопируйте его.

Подробнее: [Сохранённый черновик](./draft.md).
