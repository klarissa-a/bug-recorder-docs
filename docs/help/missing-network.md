# Не отображается Network

## Что проверить
1. Убедитесь, что действие выполнялось во время записи.
2. Проверьте, должно ли действие вообще отправлять запрос серверу.
3. Выберите фильтр **Все** и очистите **Пути API**.
4. Временно отключите **Скрывать служебные запросы**.
5. Проверьте, доступна ли информация для этой страницы.

Recorder собирает доступные fetch/XHR-запросы, а не весь трафик браузера. Подробнее: [Что записывается](../network/index.md).

Если нужный запрос всё ещё отсутствует, [сообщите о проблеме](./report-a-bug.md). Укажите действие, время запроса и его безопасный пример без секретных значений.
