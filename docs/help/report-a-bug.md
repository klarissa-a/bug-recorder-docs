# Сообщить о проблеме

## Подготовить описание
Скопируйте шаблон и заполните его. Используйте тестовые данные; удалите из вложений секретные значения.

```text
Описание проблемы:

Шаги:
1.
2.
3.

Ожидаемый результат:

Фактический результат:

Браузер:

Версия расширения:

Видео / скриншот:
```

Версию расширения можно посмотреть на `chrome://extensions`.

## Передать обратную связь
[Перейти в Telegram-канал](https://t.me/testingqabug). Уточните доступный способ обратной связи в описании или публикациях канала.

Если вы хотите предложить новую функцию или изменение сценария, откройте [Предложить улучшение](./suggest-feature.md).
