# Что такое Bug Report Recorder

Bug Report Recorder – Chrome-расширение для ручных тестировщиков. Оно помогает восстановить последовательность действий при проверке сайта и подготовить черновик баг-репорта.

## Что собирается
Во время записи Recorder формирует шаги из действий на странице, сохраняет сведения об окружении и доступные Network-запросы. Некоторые наблюдения на странице могут попасть в фактический результат.

## Что получается
После завершения открывается отчёт: заголовок, шаги, ожидаемый и фактический результаты, окружение. Проверьте и исправьте его перед отправкой. Автоматически сформированный текст может требовать уточнения.

Начните с [установки](./installation.md) или сразу выполните [первую запись](./first-recording.md).

## Версия документации
В верхнем меню указано, для какой версии Recorder написана эта инструкция. Если у вас другая версия, некоторые кнопки и возможности могут отличаться.

Чтобы узнать свою версию, откройте `chrome://extensions`, найдите **Bug Report Recorder** и нажмите **Сведения**.
