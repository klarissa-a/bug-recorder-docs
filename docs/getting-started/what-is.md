# Что такое QA Lis

QA Lis (прежнее название – Bug Report Recorder) – Chrome-расширение для ручных тестировщиков. Оно записывает действия на сайте и помогает подготовить баг-репорт или тест-кейс.

## Что собирается

Во время записи расширение сохраняет шаги, сведения об окружении, доступные fetch/XHR-запросы и сообщения Console уровня Error и Warning. Поддерживаются связанные вкладки и действия внутри поддерживаемых iframe – встроенных страниц и форм.

## Два режима

- **Баг** – шаги воспроизведения, ожидаемый и фактический результаты, окружение и диагностика.
- **Тест-кейс** – предусловие, заголовок, шаги, ожидаемый результат и необязательное постусловие. Фактического результата в нём нет.

В каждом режиме можно сохранить [до трёх записей](../recorder/records.md). После остановки открывается редактируемый отчёт. Автоматический текст нужно проверить перед копированием.

## Основные ограничения

| Данные | Ограничение |
| --- | --- |
| Баги / тест-кейсы | До 3 записей в каждом отдельном наборе |
| Шаги | До 50 на запись |
| Отдельный шаг при ручном добавлении или правке | 500 символов |
| Заголовок / предусловие тест-кейса | 300 символов каждое |
| Ожидаемый, фактический результат / постусловие | 800 символов каждое |
| Network | Последние 120 запросов каждой записи |
| Console | До 200 последних сообщений на запись; также действует ограничение общего объёма |

При достижении 50 шагов новые действия перестают добавляться. При достижении лимита Network новые запросы заменяют самые ранние: сбор продолжается. Подробнее: [Network](../network/index.md) и [Console](../network/console.md).
