# Установка

## Установка из Chrome Web Store
1. Откройте [страницу QA Lis в Chrome Web Store](https://chromewebstore.google.com/detail/bug-report-recorder/eedjhgadhogejgfhkeahnfjnmicocphi).
2. Нажмите «Установить» и подтвердите установку.
3. Откройте меню расширений Chrome и при необходимости закрепите QA Lis.
4. Откройте обычную страницу сайта, который нужно протестировать.
5. Обновите эту страницу, если она была открыта до установки.
6. Нажмите иконку расширения – после индикатора загрузки появится плавающая панель с выбором «Баг» или «Тест-кейс».

![Панель QA Lis после открытия на поддерживаемой странице](/images/recorder/ready-light.png)

## Поддерживаемые страницы
Основной браузер – Google Chrome. Также можно использовать Яндекс Браузер. Другие Chromium-браузеры требуют отдельной проверки.

Расширение работает на обычных HTTP/HTTPS-страницах. На служебных страницах браузера, например `chrome://extensions`, панель недоступна.
