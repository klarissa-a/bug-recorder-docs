# Установка

## Установка из Chrome Web Store
1. Откройте [страницу Bug Report Recorder](https://chromewebstore.google.com/detail/bug-report-recorder/eedjhgadhogejgfhkeahnfjnmicocphi).
2. Нажмите «Установить» и подтвердите установку.
3. Откройте меню расширений Chrome и при необходимости закрепите Recorder.
4. Откройте обычную страницу сайта, который нужно протестировать.
5. Обновите эту страницу, если она была открыта до установки.
6. Нажмите иконку расширения – появится плавающая панель.

## Поддерживаемые страницы
Recorder предназначен для Chrome и обычных HTTP/HTTPS-страниц. На служебных страницах браузера, например `chrome://extensions`, панель не запускается. Доступ также может ограничиваться браузером.

Поддержка других Chromium-браузеров здесь не заявляется: необходима отдельная проверка.
