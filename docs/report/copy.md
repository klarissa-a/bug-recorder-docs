# Копирование отчёта

## Скопировать текст
1. Проверьте заголовок, шаги, результаты и окружение.
2. При необходимости настройте [копирование выбранного Network-запроса](../network/requests.md).
3. Нажмите **Скопировать баг-репорт**.
4. После сообщения **Скопировано** вставьте текст в баг-трекер, YouGile, Jira, документ или сообщение разработчику.

Это обычное копирование текста через буфер обмена. Прямая интеграция с перечисленными инструментами не требуется и здесь не заявляется.

## Если копирование не удалось
Повторите нажатие. При повторной ошибке скопируйте нужные текстовые поля вручную и [сообщите о проблеме](../help/report-a-bug.md), указав браузер и версию расширения.
