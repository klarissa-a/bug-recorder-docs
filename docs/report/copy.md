# Копирование отчёта

## Скопировать текст
1. Проверьте заголовок, шаги, результаты и окружение.
2. При необходимости настройте [копирование выбранного Network-запроса](../network/requests.md).
3. Нажмите **Скопировать баг-репорт**.
4. После сообщения **Баг-репорт скопирован** вставьте текст в баг-трекер, YouGile, Jira, документ или сообщение разработчику.

Это обычное копирование текста через буфер обмена. Прямая интеграция с перечисленными инструментами не требуется и здесь не заявляется.

## Если копирование не удалось
Recorder показывает **Не удалось скопировать баг-репорт. Попробуйте ещё раз.** Повторите нажатие. При повторной ошибке скопируйте нужные текстовые поля вручную и [сообщите о проблеме](../help/report-a-bug.md), указав браузер и версию расширения.

## Если результаты ещё не заполнены
Пустые ожидаемый и фактический результаты **не блокируют копирование** и не требуют дополнительного подтверждения. Над кнопкой показывается нейтральная подсказка: результаты можно добавить сейчас или после вставки отчёта.

После успешного копирования подсказку сменяет сообщение об успехе. Если затем изменить текстовое поле отчёта, появляется **Отчёт изменён. Скопируйте его снова, чтобы перенести изменения.** Повторно скопируйте отчёт перед вставкой.
