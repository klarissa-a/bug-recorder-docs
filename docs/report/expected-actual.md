# Ожидаемый и фактический результат

## Ожидаемый результат — ОР
Опишите, что должно было произойти по требованиям или принятому поведению.

**Пример ОР:** настройка сохраняется после изменения и обновления страницы.

## Фактический результат — ФР
Опишите, что произошло на самом деле. Автоматически добавленный текст нужно проверить и при необходимости заменить.

**Пример ФР:** после обновления страницы настройка возвращается к предыдущему состоянию.

## Как сделать результаты понятными
Укажите конкретное различие. Вместо «не работает» напишите, какое значение не сохранилось или какое сообщение появилось.

Не выдавайте предполагаемую техническую причину за наблюдаемый факт. При необходимости добавьте связанный [Network-запрос](../network/requests.md).
