# Окружение

## Что добавляется
В зависимости от доступных данных Recorder формирует окружение:
- URL страницы или сайт, стартовую страницу и маршрут переходов;
- размер видимой области страницы — **Viewport**;
- размер экрана;
- масштаб браузера;
- название и основную версию браузера;
- операционную систему.

## Проверить и исправить
Поле **Окружение** можно редактировать. Если данные не определились или не отражают условия ошибки, уточните их вручную.

Название **Windows** без номера версии допустимо: браузер не всегда позволяет надёжно отличить Windows 10 от Windows 11.

Размер экрана и Viewport различаются: Viewport описывает область страницы внутри окна браузера.
