# Структура отчёта

После **Завершить запись** открывается отчёт выбранного режима. Для [тест-кейса](./test-case.md) набор полей отличается.

## Баг-репорт

| Раздел | Что проверить |
| --- | --- |
| [Заголовок](./title.md) | Наблюдаемую проблему, место и условие её появления |
| [Шаги воспроизведения](../steps/edit.md#в-готовом-отчете) | Полноту, порядок и названия действий |
| [Ожидаемый и фактический результаты](./expected-actual.md) | Разницу между требуемым и наблюдаемым поведением |
| [Network](../network/requests.md) и [Console](../network/console.md) | Запросы и сообщения, связанные со сценарием |
| [Окружение](./environment.md) | Страницу, браузер и условия отображения |

![Полный баг-репорт QA Lis: поля, Network, окружение и кнопка копирования](/images/report/report-fields-light.png)

На снимке – учебный сценарий с ошибкой сохранения. Ожидаемый результат заполнен вручную, фактический результат сформирован по сообщению страницы.

## Навигация и сворачивание

Кнопки **Шаги**, **Окружение**, **Network** прокручивают отчёт к нужному разделу. Кнопки **Баг 1**, **Баг 2** сверху переключают записи набора.

Чтобы освободить место на сайте, сверните готовый отчёт. Не путайте эту кнопку с крестиком закрытия:

## Перед копированием

Проверьте текст и автоматический выбор данных диагностики. Network и Console настраиваются независимо; выбранная ошибка может уже быть включена в копию. Нажмите **Скопировать баг-репорт**. Подробнее: [Копирование](./copy.md).
