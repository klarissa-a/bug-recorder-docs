# Структура отчёта

После **Завершить запись** открывается редактируемый черновик баг-репорта.

## Разделы отчёта
| Раздел | Что проверить |
| --- | --- |
| [Заголовок](./title.md) | Что произошло, где и после какого действия |
| Шаги воспроизведения | Полноту и порядок действий |
| [Ожидаемый результат](./expected-actual.md) | Что должно было произойти |
| [Фактический результат](./expected-actual.md) | Что произошло в действительности |
| [Окружение](./environment.md) | Страницу, браузер и параметры отображения |
| [Network](../network/index.md) | Запрос, связанный с проблемой |

## Перед отправкой
Все текстовые поля отчёта можно отредактировать. Автоматически собранные шаги и фактический результат могут быть неточными.

После проверки нажмите **Скопировать баг-репорт**. Добавление Network в скопированный текст настраивается [отдельно](../network/requests.md).
