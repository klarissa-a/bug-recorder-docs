# Работа с запросами

## Найти запрос
В разделе Network отчёта доступны фильтры **Все**, **Ошибки**, **REST** и **GraphQL**.

В поле **Пути API** можно указать начальный путь, например `/api/` или `/graphql`. Несколько путей разделяются запятыми.

Чтобы увидеть скрытые служебные запросы, отключите **Скрывать служебные запросы** или нажмите **Показать** рядом с их количеством.

## Посмотреть детали
Откройте строку запроса. Вкладка **Запрос** содержит Headers и Payload, вкладка **Ответ** — Headers и Response. Кнопки **Копировать** позволяют скопировать отдельные блоки. **К Network** возвращает к списку.

## Добавить запрос в текст баг-репорта
В блоке **При копировании баг-репорта**:
- **Не копировать** — Network остаётся в расширении и не включается в текст;
- **Копировать выбранный** — в текст включаются данные выбранного запроса.

Проверьте выбранный запрос и режим перед нажатием **Скопировать баг-репорт**.
