# Работа с запросами

## Найти запрос

Откройте **Network** в отчёте. Поле **Поиск по URL, домену или пути** ищет нужный адрес. Быстрые кнопки **Все**, **Ошибки**, **REST**, **GraphQL** помогают сузить список.

Нажмите **Фильтры**, чтобы выбрать:

- HTTP-метод;
- домен – в длинном списке доступен поиск;
- статус, включая конкретный HTTP-код из записанных запросов;
- тип запроса;
- скрытие служебных запросов.

Все условия работают вместе. Выбранные фильтры показываются отдельными метками: их можно снять по одному. **Сбросить фильтры** возвращает исходные фильтры, сохраняя строку поиска; для полного сброса очистите и её. Рядом со счётчиком служебных запросов доступно **Показать / Скрыть**.

![Раскрытые дополнительные фильтры Network](/images/network/filters-light.png)

Фильтр может скрыть выбранный запрос, не снимая его выбор. Перед копированием проверьте подпись выбранных данных.

## Детали запроса

Нажмите **Детали** в строке запроса. **Запрос** показывает Headers и Payload.

![Вкладка «Запрос»: заголовки и отправленные тестовые данные](/images/network/request-light.png)

**Ответ** показывает Headers и Response. Кнопки **Копировать** копируют отдельные текстовые блоки.

![Вкладка «Ответ»: HTTP 503 и JSON с сообщением ошибки](/images/network/response-light.png)

**Расшифровать** показывает пояснение запроса и возможной причины. Это подсказка, а не подтверждённый диагноз. **К Network** возвращает к списку.

## Включить в отчёт

В блоке **При копировании баг-репорта** выберите **Не копировать** или **Копировать выбранные**. Отметьте до **трёх запросов**: их request и response попадут в копию в хронологическом порядке, с отдельными нумерованными заголовками. Чтобы выбрать четвёртый, сначала снимите одну отметку. Выбор сохраняется при фильтрации и отдельно для каждой записи.

При автоматически распознанной прикладной ошибке режим может включиться сам, если вы ещё не задали его вручную. Проверьте выделение и подпись перед копированием. Для исключения запроса нажмите **Не копировать**.

Режим Console настраивается отдельно. В скопированном отчёте могут присутствовать и запрос, и сообщение Console.
