# Что записывается

## Что такое Network
Во время сценария сайт отправляет запросы серверу и получает ответы. Recorder собирает доступные запросы fetch/XHR, чтобы помочь найти запрос, связанный с проблемой.

Это не полный журнал всех соединений браузера: отсутствие строки в Recorder не доказывает, что сетевой активности не было.

## Доступные данные
В зависимости от запроса можно увидеть URL, HTTP-метод, статус, заголовки, отправленные данные **Payload** и содержимое ответа **Response**.

Большие данные могут обрезаться. Некоторые тела запросов и ответов недоступны или представлены кратким описанием. Распознанные секреты маскируются.

## Служебные запросы
Функция **Скрывать служебные запросы** уже реализована. Она скрывает из списка распознанные запросы аналитики, рекламы и статистики, не удаляя их. Запросы с распознанными ошибками остаются видимыми.

Счётчик рядом со статусом записи не обязательно равен числу всех строк Network: часть фоновых запросов не учитывается.

Далее: [Работа с запросами](./requests.md).
