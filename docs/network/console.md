# Ошибки и предупреждения Console

## Что собирается

QA Lis сохраняет сообщения **Error** и **Warning** со связанных страниц и поддерживаемых iframe во время записи. Обычные `console.log` не являются частью этого списка. Сообщения связываются с шагом, если подходящий шаг удалось определить.

В диагностике отчёта нажмите **Console**. Доступны фильтры **Все**, **Ошибки**, **Warnings**.

![Console в отчёте: ошибка и предупреждение после сохранения настроек](/images/network/console-light.png)

## Посмотреть сообщение

Нажмите **Детали**. Вкладка **Сообщение** показывает текст, источник, строку и колонку, страницу, время и связанный шаг. **Stack trace** содержит стек, если он доступен. Кнопки копирования позволяют перенести сообщение или стек отдельно.

![Детали ошибки Console с полным текстом и источником](/images/network/console-details-light.png)

**Расшифровать** открывает пояснение события и возможной причины. Текст самого сайта не переводится при смене RU / EN.

## Копирование в отчёт

Последнее Error может выбираться автоматически с включением копирования, если режим ещё не задан вручную. Выберите **Не копировать**, чтобы исключить Console, или **Копировать выбранный**, чтобы добавить одно выбранное сообщение.

Настройки Network и Console независимы. Смена вкладки диагностики не отключает ранее выбранный блок.

## Ограничения

На запись сохраняется до **200 последних сообщений**; также действует ограничение общего объёма. При замене старых сообщений появляется уведомление; большое отдельное сообщение может быть сокращено с пометкой. Это не полный архив консоли DevTools.

Распознанные секреты маскируются. Перед передачей проверьте сообщение и стек: в них могут быть данные, которые сайт не обозначил как чувствительные.
