# Поля ввода

## Обычные поля
Заполнение текстового поля может стать отдельным шагом. В нём может отображаться введённое значение, если поле не распознано как чувствительное.

Пример с тестовыми данными: «Заполнить поле „Название“ значением „Тестовая заметка“».

## Пароль и чувствительные данные
Для поля пароля фиксируется действие ввода без самого пароля. Распознанные чувствительные значения маскируются. В Network это также относится к паролям, cookie, токенам, заголовкам авторизации и API-ключам.

Перед отправкой проверьте текст отчёта и технические данные, особенно если сайт использует нестандартные поля. Для примеров, видео и скриншотов используйте тестовые данные.

Если секрет оказался виден, не отправляйте его: опишите тип поля и приложите только обезличенный пример в [сообщении о проблеме](../help/report-a-bug.md).
