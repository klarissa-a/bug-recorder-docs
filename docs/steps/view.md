# Просмотр шагов

## Последние шаги
Нажмите **Шаги N**. По умолчанию отображаются последние четыре шага в порядке записи. Если действий меньше, видны все имеющиеся.

В полной панели список находится внутри неё. В мини-панели открывается отдельный всплывающий блок.

![Последние четыре шага из восьми внутри полной панели; рядом с каждым шагом есть карандаш и корзина](/images/steps/recent-steps-light.png)

![Открытый список шагов под кнопкой «Шаги 1» мини-панели](/images/steps/mini-steps-light.png)

## Все шаги
Если шагов больше четырёх, нажмите **Все шаги**. Список развернётся в том же блоке; при большой длине его можно прокручивать. Баг-репорт при этом не открывается.

Сокращённый список удобен для проверки последнего действия, полный — для просмотра всего сценария.

## Скрыть список
Нажмите **Скрыть**. Записанные данные сохранятся.

Под списком указано, сколько шагов показано. Счётчик **Шаги N** относится к действиям, а количество запросов рядом со статусом — к Network.
