# Просмотр шагов

## Открыть список

Нажмите **Шаги N**. До первого действия число не показывается. Список относится к выбранному багу или тест-кейсу.

По умолчанию видны последние четыре шага в порядке записи. Если их меньше, показываются все имеющиеся. В полной панели список находится под статусом.

![Три шага выбранного бага в полной панели](/images/steps/recent-steps-light.png)

В мини-панели список открывается отдельным всплывающим блоком.

![Мини-панель с раскрытым списком шагов](/images/steps/mini-steps-light.png)

## Все шаги

Если действий больше четырёх, нажмите **Все шаги**. Полный список откроется в том же блоке; длинный список можно прокручивать. Отчёт при этом не открывается.

Под списком указано число показанных шагов. **Скрыть** закрывает список, сохраняя данные.

## Проверить и исправить

У каждого шага доступны правка, удаление и перемещение. **Добавить шаг +** позволяет дописать действие вручную. Подробнее: [Редактирование и порядок](./edit.md).

После остановки откройте сохранённый отчёт: в нём шаги редактируются общим текстовым полем со счётчиком **N/50**.
